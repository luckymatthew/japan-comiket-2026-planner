# Japan × Comiket 109 Trip Planner

Static GitHub Pages copy of the Japan × Comiket 109 planning dashboard.

## Publish

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Open **Actions** and run **Deploy static site to GitHub Pages** if the first deployment has not started automatically.

The published URL will be shown in the deployment summary.

## Local preview

Serve this directory with any static web server, for example:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
